# Mobile and Latest iPhone Standard

## 保证范围

- 核心保证：最新正式发布的 iPhone 硬件与其最新正式 iOS。
- 当前验证基线：iPhone 17、iOS 26.6；基线变化时更新 registry、测试证据与本文件，不默认为 beta 系统背书。基线依据 [Apple 当前 iPhone 产品线](https://www.apple.com/iphone/) 与 [Apple iOS 26.6 安全发布记录](https://support.apple.com/en-us/128066)，核验于 2026-09-04。
- Web 端必须可运行，但布局、触控、键盘与声音决策以移动端为先。
- 不承诺旧 iPhone、旧 iOS 或 iPad；若项目自愿支持，写入自己的 `TESTING.md`。

## 组件行为

- 使用 `100dvh`、四边 safe-area、最小 44×44 pt 触控目标和可见焦点。
- 320×568 不得隐藏核心动作；390×844 是常规自动化基线。
- 固定底栏必须避开 Home Indicator；键盘出现时核心字段与提交按钮仍可见或可滚动到达。
- 竖屏为默认；横屏不可崩溃、遮住退出按钮或丢失进度。
- 禁止只依赖 hover、右键、鼠标精确拖拽或双指手势。
- 动效尊重 `prefers-reduced-motion`，反馈仍须通过颜色之外的方式可理解。

## iOS 声音与权限

- 音频只能在用户首次有效交互后创建或恢复。
- 静音控制始终可触达，并持久化到本地。
- 相册、位置等权限在用户触发对应功能时才请求；拒绝后提供清楚的无权限路径。
- 不在启动时弹权限，不将权限拒绝视为流程失败。
