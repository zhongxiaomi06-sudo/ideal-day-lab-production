# 钟笑咪工作与审美偏好

## 身份与目标

- 姓名/固定称呼：钟笑咪。
- 当前身份：以实习身份为 Eazo 创作 miniapp。
- 产品目标：解决一个很小、高频且让用户难受的问题，让人立刻想用并立即获得有用结果。

## 工作方式

- Agent 每次只问一个问题；模糊反馈用一个开放问题逐步澄清。
- 创意和设计只提交一个最推荐方案。
- 默认先提交一张核心页面视觉稿，通常是首页；特殊情况最多两张。
- 钟笑咪回复“通过”后才完整开发。视觉预览提交后暂停，等待反馈。
- 视觉方向确认后只在关键决策时询问。体验等价的技术简化可以自主采用，但必须立即说明。
- 功能可用但测试未全部通过时可以先提交“预览/待验证”，随后暂停等待视觉反馈。
- 最终回复只给简短结论和文件入口；详细证据写入项目文档。

## 产品与交互

- 第一判断是“我会不会想点进去”；首页信息强烈，让用户大致知道用途即可。
- 点击后直接开始，不放教程；默认一页只处理一个输入或决定。
- 多步骤体验像连续对话，保留明显返回入口。
- 完成态优先是一张可保存、完全无品牌的视觉卡片；界面品牌也保持克制。
- 声音是默认体验组成。Eazo Feed 离开即停止，刷回从头开始。

## 视觉偏好

- 图片为主、卡片结果优先、图片信息丰富但层级清楚、文字少。
- 内容是前提；构图秩序优先于色彩，色彩优先于光影。
- 偏好自然抓拍，重视线条与色彩；拒绝混乱和元素不和谐。
- 使用少量但强烈的主色、大块色彩和少量辅助色。
- 偏好编辑感、杂志感的衬线字体，但所有选择服从整体视觉。
- 动效用于顺畅和沉浸，不用于炫技。
- 页面复刻追求整体感受一致；需要精确还原的特殊细节由钟笑咪主动指出。

## 素材与权利

- 图片质量优先，可使用免费或付费来源。
- 核心素材类型是真实摄影和电影海报。
- 正式工程只采用明确允许商业使用的素材，并保留完整来源和许可记录。
- 社交平台图片只作参考，可借鉴抽象视觉特征重新创作，不直接修改后交付。
- 缺少合规海报时允许 Agent 生成原创替代视觉；仍不合适时由钟笑咪提供素材。
- DAM 素材只新增版本、不覆盖旧版。风险素材停止新项目使用，最终处置由钟笑咪决定。

## 产品证据

- Agent 主动提出或尚未确认的创意，至少需要最近五年内 50 条独立、可追溯、去重后的真实反馈。
- 来源平台数量不限；是否主动搜索反例由 Agent 判断，重要反例必须报告。
- 钟笑咪明确指定的项目可直接进入视觉稿阶段。
